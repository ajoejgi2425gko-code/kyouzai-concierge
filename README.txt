教材選定コンシェルジュ（ことパパのAIコンシェルジュ）

【公開方法】
ZIPを解凍し、すべてのファイルをGitHubリポジトリのルートにアップロード。
Settings > Pages で main / (root) を選択してください。
推奨リポジトリ名：kyouzai-concierge

【おすすめ教材の登録】
catalog.json は初期状態で []（登録なし）です。未検証の教材を最初からおすすめとして表示しないためです。
資格ごとの教材を確認したら、次の形式のオブジェクトを配列に追加してください。
[
  {
    "exam": "日商簿記2級",
    "aliases": ["簿記2級", "日商簿記２級"],
    "title": "実際に確認した教材の正式名称",
    "publisher": "出版社名",
    "edition": "版・年度",
    "note": "特徴や対象者を簡潔に",
    "url": "https://出版社または正規の販売ページのURL"
  }
]
上記は入力例であり、実在教材の推薦ではありません。
アフィリエイトリンクを設定する場合は、提携規約を守り、掲載ページに広告・PR表記を行ってください。
教材の価格や対応年度などは定期的に確認してください。

【仕様】
AI APIは使用しません。相談文を生成してコピーし、ChatGPT/Gemini/Copilotを開きます。
相談文は自動送信されません。初回読み込み後、フォームと相談文生成はオフラインでも利用できます。
外部AIサイトの利用にはネット接続が必要です。
